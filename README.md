# 🚀 LaunchPad

### One-Click Full-Stack Project Launcher

LaunchPad is a desktop application designed to simplify local development workflows.

Instead of manually opening IDEs, terminals, backend services, frontend applications and browser tabs every time you start working on a project, LaunchPad allows you to register your services once and run everything with a single click.

---

## ✨ Features

✅ Register Frontend and Backend startup scripts

✅ Save project configuration locally

✅ One-click service startup

✅ Automatic browser launch

✅ Live service monitoring

✅ Real-time console logs

✅ Service status indicators

✅ Start / Stop full-stack applications

✅ Persistent configuration storage

---

## 🎯 Why I Built This

While working on multiple full-stack projects, I noticed that I was repeating the same workflow every day:

1. Open IDE
2. Open terminal
3. Navigate to backend directory
4. Start backend
5. Open another terminal
6. Navigate to frontend directory
7. Start frontend
8. Open browser
9. Visit localhost

The process was repetitive and time-consuming.

LaunchPad was created to automate this workflow and reduce project startup to a single click.

---

## 🏗️ Architecture

LaunchPad works in two stages:

### Step 1 — Generate Startup Scripts

A utility tool generates startup scripts for:

* Frontend applications
* Backend services

### Step 2 — Register & Launch

LaunchPad:

* Registers startup scripts
* Stores project configuration
* Launches services in the correct order
* Opens the browser automatically
* Displays logs and status information

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/yourusername/launchpad.git
```

### Install Requirements

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python project_manager.py
```
